# BlogGeneratorApp 📝🤖

**BlogGeneratorApp** is an automated blog generation and posting tool built with **ASP.NET MVC 8** and powered by **OpenAI’s ChatGPT API**. It automatically creates and publishes a new blog post every day based on customizable topics or keywords.

## 🌟 Features

- ✅ Daily blog generation using OpenAI ChatGPT
- 🎯 Customizable topic or keyword-based content
- 🕒 Auto-scheduling with CRON/Task Scheduler or Hangfire
- 🗂️ Blog history and output management
- 🧠 High-quality, SEO-friendly writing
- 🛠 Built with .NET 8 / ASP.NET MVC

## 🚀 Getting Started

### Prerequisites

- [.NET 8 SDK](https://dotnet.microsoft.com/en-us/download/dotnet/8.0)
- Visual Studio 2022 or later
- OpenAI API key

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Buntysoni/BlogGeneratorApp.git
   cd BlogGeneratorApp

2. **Put your ChatGPT api key (appsettings.json):**
   ```bash
   "OpenAI": {
     "ApiKey": "your_openai_api_key"
   }
